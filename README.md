# FitnessChile - Plataforma Web y Tienda Oficial

Plataforma web de comercio electrónico y vitrina digital para **FitnessChile**, especializada en la venta y distribución nacional de equipamiento deportivo, pesas de fabricación nacional, máquinas de estándar olímpico y suplementación de alto rendimiento.

---

## 📋 Descripción del Proyecto

Este proyecto corresponde a una solución web integral estructurada bajo estándares modernos de desarrollo Front-End (HTML5 semántico, CSS3 modular responsivo y JavaScript Vanilla con validación interactiva).

### Características Principales:
* **Estructura Semántica W3C:** Maquetación modular con `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **Navegación e Interconexión:** Páginas funcionales interconectadas (`index.html`, `productos.html`, `contacto.html`, `nosotros.html`, `blog.html`).
* **Diseño UI/UX Responsivo:** Hoja de estilos externa (`css/style.css`) con CSS Grid, Flexbox y adaptabilidad móvil.
* **Validación en Tiempo Real:** Motor de validación de formularios en JavaScript (`js/app.js`) con retroalimentación visual accesible.
* **Integración Multimedia:** Hero slider dinámico y reproductor multimedia responsivo 16:9.

## 📑 Especificación de Requisitos de Software (ERS)

### 1.4. Visión General del Documento
El marco documental de Especificación de Requisitos de Software (ERS) de este proyecto está organizado en áreas clave para guiar el ciclo de vida del software:

1. **Área de Definición del Negocio:** Delimita el propósito comercial, contexto estratégico, público objetivo y objetivos de la plataforma *FitnessChile*.
2. **Área de Descripción General y Requisitos:** Especifica la perspectiva del producto, perfiles de usuario, dependencias técnicas, así como el catálogo riguroso de **Requisitos Funcionales (RF)** y **Requisitos No Funcionales (RNF)** (desempeño, accesibilidad, diseño adaptable y seguridad).
3. **Anexos y Formularios de Casos de Uso:** Proporciona el detalle operativo de los requerimientos mediante formularios de Casos de Uso (CU) que describen flujos principales, alternativas de interacción y condiciones del sistema.
